About Navixo

Navixo, developed by Wasif Ahmed Khan, is a secure, privacy-focused live location-sharing Android application designed for families and close friends. Built to be completely free to operate, the app provides users with granular control over their location data through time-limited sharing options and customizable battery-saver GPS intervals. Its standout feature is "Incognito Mode," which allows users to freeze their broadcasted location at a designated safe zone, ensuring personal privacy without causing worry for their loved ones.

Frameworks & Technologies

Engineered with clean architectural separation and modern native Android Jetpack libraries:

Kotlin Core language utilizing Coroutines & Flow for reactive asynchronous streams.
Jetpack Compose Declarative UI architecture with Material 3 styling and responsive view rendering.
Osmdroid (OpenStreetMap) Open-source, privacy-preserving interactive map rendering with zero vendor lock-in.
Foreground Service Persistent background location dispatcher with notification-level control.
MVVM Architecture ViewModel, Repository pattern, and clean UI state separation for testability.
Local Credentials Encrypted local preferences for session authentication and privacy presets.

Core Features

Real-Time Coordination

Smooth GPS coordinate streaming that keeps circle members updated on current location and travel heading.

Incognito & Ghost Mode

Fuzz your location radius or pause updates with a single tap whenever you need personal privacy.

Timed Sharing Sessions

Set sharing durations (15m, 1h, 8h) that automatically terminate tracking once the timer expires.

Battery Optimized

Smart motion-sensor heuristics that adjust GPS polling frequency based on whether you are walking or stationary.
